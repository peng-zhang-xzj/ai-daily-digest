# L9 如何评判:把一次评测从「原始输出」算到「一个可信的数」

建议授课30–35分钟。前置:知道 VLM 能做问答/OCR/定位等任务;听过精确率/召回率更好,没听过本讲也会定义。

学完应能:按能力维度(而非榜名)记住主流 benchmark;把一次评测从模型原始输出一路算到最终分数(提取→规范化→判分→聚合);手算一次 IoU 和一次 POPE 的 P/R/F1;用 yes-ratio 和退化基线识破「假高分」;并说清小样本的不确定性。

## 2. 一次评测不是「跑个分」,而是一条链路

很多人以为评测就是「模型答对没」。实际上,从模型吐字到最终榜分,中间每一步都可能出错或被操纵。完整链路:

[[fig:scoring]]

### 走一个具体例子(选择题)

题目:「图里有几个人?(A)1 (B)2 (C)3」,标准答案 B。

```text
① 模型原始输出:"根据图像,我认为应该是 (B) 两个人。"
② 答案提取:用规则/正则从这段话里抠出选项字母 → "B"
③ 规范化:去空格、统一大小写、全角转半角 → "B"
④ 判分:与标准答案 "B" 比对 → 命中(1 分)
⑤ 聚合:所有题的命中数 / 题数 → 该 benchmark 的准确率
```

**提取这一步最容易出事**。换一个模型,原始输出是「图里有**两个人**」——答案明确正确,但它**没写出选项字母 B**。这时两种提取规则会给出不同结果:

- **严格字母提取**:只认选项字母,抠不到「B」→ **判错**。
- **语义提取 / 答案映射**:把「两个人」映射到选项 B → **判对**。

同一个明确正确的回答,因为提取规则不同,分数就不同。这就是为什么「换 prompt / 换提取规则,分数就变」——报告评测必须交代**用的是严格还是语义提取**。

### 开放式题怎么判:LLM 裁判的坑

选择题能自动判;**开放式回答**(如 MM-Vet)常用另一个强 LLM 当裁判打分。要可信,必须固定并公开:**评分 rubric(打分标准)、裁判模型的 id 与版本、以及是否控制长度偏差**——LLM 裁判普遍**偏好更长的回答**,不控制就会把「话多」误判成「更好」。换个裁判版本,同一批回答分数可能明显变化,所以比较开放式分数一定要同裁判、同 rubric。

## 3. 手算一次 IoU(grounding 怎么判分)

定位任务要模型框出物体,用**交并比(IoU)**判对错:预测框和标注框的交集面积 ÷ 并集面积。

```text
预测框  P:左上(10,10) 右下(50,50)  → 面积 40×40 = 1600
标注框 GT:左上(30,30) 右下(70,70)  → 面积 40×40 = 1600

交集:x 方向 [30,50] 宽20;y 方向 [30,50] 高20 → 20×20 = 400
并集:1600 + 1600 − 400 = 2800
IoU = 400 / 2800 ≈ 0.143
```

常用阈值 0.5:IoU=0.143 < 0.5 → **判为未命中**。

### 文本匹配:规范化要适度,别把信息删掉

DocVQA/OCR 这类比对文本答案前要**规范化**,但规范化过头会误伤。举例,标准答案是金额 `$1,234.50`:

```text
合理规范化:去首尾空格、统一大小写、全角转半角
           "  $1,234.50 "  → "$1,234.50"        ✓ 仍可正确匹配
过度规范化:删掉所有标点(含小数点和千分位)
           "$1,234.50"  → "123450"               ✗ 语义变了,1234.5 元变成 123450
```

**小数点、负号、千分位这些是有意义的字符,不能当标点一删了之**;同义/大小写可以归一,数值格式要谨慎。规范化规则本身就是评测的一部分,要写清楚。

## 4. POPE:混淆矩阵 + 手算 + 用 yes-ratio 识破退化

POPE 问一堆「图里有没有 X?」的是/否题,当二分类统计四个数:

[[fig:confusion]]

精确率 P = TP/(TP+FP);召回率 R = TP/(TP+FN);F1 = 2PR/(P+R)。

**算例**:TP=40, FP=10, FN=20, TN=30。

```text
P = 40/(40+10) = 0.80
R = 40/(40+20) = 0.667
Accuracy = (40+30)/100 = 0.70
F1 = 2·0.8·0.667/(0.8+0.667) ≈ 0.727
yes-ratio = (模型答"有"的次数)/总数 = (40+10)/100 = 0.50
```

### 为什么必须看退化基线和 yes-ratio

先看两条**退化基线**(不是真会,只是蒙):

```text
全答"有":  命中所有真有(TP)、误报所有真没有(FP) → Recall=100% 但 Precision 低, yes-ratio=1.0
全答"没有":漏判所有真有(FN)、放过所有真没有(TN) → Recall=0%,          yes-ratio=0.0
```

关键:**yes-ratio 要对照测试集的「真实正例率」来读,不是一律看 0.5**。0.5 只适用于**正负样本平衡**的集。拿上面的算例:真有 = TP+FN = 60,真没有 = FP+TN = 40,所以**真实正例率 = 0.60**;而模型 yes-ratio = 0.50,其实比真实正例率略低(偏保守),并不是在作弊。所以:

- 参照点是**真实正例率**,不是固定的 0.5;
- yes-ratio 严重偏离真实正例率(尤其贴近 1.0 或 0.0)才需警惕退化;「全答有/全答没有」只作**退化基线**对照,偏离本身**不等于**就是作弊。

读 POPE 要同时看 P、R、yes-ratio 与真实正例率。而且 **FP 就是幻觉**——这正是 POPE 想暴露的:爱「脑补存在」的模型 FP 高。

## 5. 小样本的不确定性:别拿噪声当结论

评测样本越少,分数的随机波动越大。准确率的标准误约为 `sqrt(p(1−p)/n)`。

```text
p=0.70, n=100  → 标准误 ≈ sqrt(0.7·0.3/100) ≈ 0.046
95% 区间大约 ±2 个标准误 ≈ ±9 个百分点
```

也就是说,只测 100 条时,0.70 的分数真实值可能在 0.61–0.79 之间晃。**所以小样本上「A 比 B 高 0.5 个点」几乎没有意义**。

**两个重要前提别忽略**:① 这个 `sqrt(p(1−p)/n)` 是**独立二项近似**,假设每道题相互独立;但 POPE 里**同一张图常配多道问题,彼此相关**,真实不确定性可能比公式更大。② 要比较两个模型,别只各画一条边际区间就下结论,应做**题目级配对**(同题比对)或 **bootstrap** 重采样来估计差值的不确定性。报告评测必须给:每个任务的**样本数**、是否分组(按题型/难度)、以及明确「这是小样本,不声称全集成绩」。

## 6. 读榜 5 条防骗原则

1. **数据污染**:测试集漏进训练 → 虚高。看报告有没有做训练—评测去重。
2. **设置不一致**:换 prompt/分辨率/提取规则分数就变,比较要同设置。
3. **选择题 ≠ 真实能力**:多看开放式和真实世界榜。
4. **单榜领先 ≠ 全面强**:看一组榜的画像。
5. **平均分掩盖偏科 + 掩盖退化**:按用途看对应维度,并看 yes-ratio 等退化指标。

## 7. 特别提醒:POPE 高分 ≠ 可靠,更 ≠ 内容安全

POPE 只检测「某类对象是否存在」这一类是/否幻觉,**不是整体可靠性或内容安全的证明**。想把 VLM 用于内容/账号安全,还得看该任务自己的数据、FP/FN 与**误判成本**、漏判、拒答、分布变化下的稳健性。幻觉榜能暴露问题,但不能替你证明「能上线」。

> **能力画像速查**:给一个新模型,看这 6 个数快速画像——MMMU、MMBench、DocVQA/OCRBench、ChartQA、MathVista、POPE(连同其 yes-ratio)。但上线前务必补该场景自己的评测。

## 练习

1. 模型明确答「两个人」但没写出选项字母 B,严格提取和语义提取会怎么判?说明什么? —— 答案:严格字母提取抠不到 B 判错;语义提取把「两个人」映射到 B 判对。说明分数受提取规则影响很大,报告须交代用严格还是语义提取。
2. 预测框(0,0)-(20,20)、标注框(10,10)-(30,30),IoU 是多少,按 0.5 阈值命中吗? —— 答案:交集 10×10=100,并集 400+400−100=700,IoU≈0.143 < 0.5,未命中。
3. POPE 里哪个格子是「幻觉」?yes-ratio 该跟谁比,=0.95 一定是作弊吗? —— 答案:FP(图里没有却答有)是幻觉。yes-ratio 要对照测试集**真实正例率**看,不是固定比 0.5;若真实正例率也接近 0.95,则不算异常。只有严重偏离真实正例率(尤其贴近 1.0/0.0)才警惕退化,偏离本身≠作弊。
4. 只测 100 条、准确率 0.70,能说它显著强于另一个 0.69 的模型吗? —— 答案:不能。标准误约 0.046,±9 个百分点,0.70 与 0.69 的差远在噪声内。
5. 已知 TP=30, FP=30, FN=10, TN=30,算 P、R、yes-ratio。 —— 答案:P=30/60=0.5;R=30/40=0.75;yes-ratio=(30+30)/100=0.6。精确率低说明误报多(爱脑补)。

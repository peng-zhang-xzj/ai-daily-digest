# L7 视觉tokenizer：连续特征、离散码本与图像生成究竟是什么关系

建议时长40–45分钟。前置：L4的连续视觉输入；本讲解释最近邻量化、重建和梯度。学完应能手算一个码本选择，区别token数量与词表大小，画出离散图像生成流程，并说明连续输入为什么不排斥图像生成。

## 1. 先拆开“token”这个多义词

文本tokenizer把文字分成词表里的离散id，例如某个子词对应整数218；embedding表把这个id查成向量。token是离散符号，embedding是它在神经网络中的向量表示，二者不是同一个对象。

LLaVA式视觉路径里，ViT输出很多位置的连续特征，连接器把每行映到LLM宽度。大家也称这些位置为“视觉token”，但它们没有必然对应离散词表id。因此先问“这个token是离散符号，还是序列中的一个连续向量位置”，很多混乱就消失了。

编码器把图片变成连续表示；视觉tokenizer在狭义离散意义下还需把表示映到有限码本。实际论文对“tokenizer”的叫法并不完全统一，讨论具体模型时应描述操作，而不是只争名称。

## 2. 连续理解路径为什么常见

连续表示不必将每个位置强制归到有限的离散原型，容易复用CLIP/SigLIP等视觉编码器，并直接适配语言输入。因此很多理解型VLM使用这条路线。

但它也有压缩：图片预处理、patch化、有限宽度、空间合并与query读取都可能丢信息。不能把“连续”说成数学上保留原图所有细节，或把其输出称为原图重建。

这类理解模型默认用词表读出头生成文字，是输出结构和训练目标的选择。**连续输入本身没有证明模型一定不能生成图片**：后面若连接图像生成模块、扩散/flow解码器，或采用分离的生成视觉表示，系统同样可以产生图像。

## 3. 离散路径的完整链路，不是直接给像素换颜色

一个典型离散视觉自编码器（autoencoder，用输入图像本身作为重建目标的模型）可分三步：编码器E把图片压成潜网格z；量化器把每个连续向量选成码本条目；解码器D把量化后的潜网格重建成图片。

```text
图像 I → 编码器 E → 连续潜网格 z [h,w,d]
                         ↓ 每位置最近邻
                    离散id网格 k [h,w]
                         ↓ 查码本
                    量化潜网格 e [h,w,d]
                         ↓ 解码器 D
                    重建图像 I_hat
```

码本C有K个向量，形状为`[K,d]`。每个潜位置zᵢ选择：

`kᵢ = argminₖ ||zᵢ−Cₖ||²`，量化输出`eᵢ=C[kᵢ]`。

argmin返回“哪个条目距离最小”的索引。解码时先查码本恢复向量，再由神经解码器恢复像素，不能把离散id本身当成RGB颜色。

## 4. 最近邻手算：看清量化丢失在哪一步

[[figure:l7-vq-nearest]]

设一个潜向量z=(0.8,0.6)，码本只有两个条目C₀=(1,0)、C₁=(0,1)。到C₀的平方距离为`(−0.2)²+0.6²=0.40`，到C₁为`0.8²+(−0.4)²=0.80`，所以选择id0，查表得到(1,0)。

z原来的两个精确值不再保留，多个不同z可能映到同一个id。这是量化的信息瓶颈。若再增加条目(0.8,0.6)，这个位置量化误差可以变为0，但是否提升实际重建/理解还要看码本整体训练和解码器。

增加K且保留旧码本时，“最小平方距离”不会变大，因为旧选择仍在候选里。若每次独立重训不同码本，则没有逐位置单调保证；若最近邻按平方距离选、报告另一个误差指标，也不能无条件推出报告指标单调。

## 5. K与网格尺寸分别决定什么

[[figure:l7-codebook-count]]

假设编码后网格16×16，共256个离散位置。K=1024与K=8192都还是256个id，不会因为词表扩大8倍，就多出8倍token。

理想固定长度二进制存储中，一个K=1024的id需10bit，K=8192需13bit。于是忽略边界、码本存储和熵编码，256个id分别需要2560与3328bit。`log₂K`描述一个id的符号容量；网格h×w描述序列有多少个位置。

若空间下采样从16倍改成8倍，同一原图的潜网格每边增大2倍，token数增大4倍。这更直接改变自回归生成步数。码本大小还会影响输出分类头的类别数与训练，但不等于空间分辨率本身。

## 6. argmin不可微，训练如何继续

“选最近条目”的索引对小扰动往往不变，跨边界又突然跳变，不能像普通线性层那样给编码器提供有用梯度。常见VQ训练采用straight-through估计及辅助损失。

三个主要目标可以示意为：

```text
L_recon = 图片重建损失(D(e), I)
L_code  = ||stopgrad(z) − e||²       让码本靠近编码器输出
L_commit= β ||z − stopgrad(e)||²     让编码器别远离所选码本
L = L_recon + L_code + L_commit
```

stopgrad表示前向值保留，但这条边不传反向梯度。straight-through让前向使用量化值、反向对编码器近似当成恒等路径：`z_st = z + stopgrad(e−z)`。这样重建梯度可回到编码器，码本主要通过自己的损失或某些实现中的EMA更新。

β控制commitment力度；太小可能编码器漂移，太大可能妨碍重建。真实视觉tokenizer还可能使用感知损失、对抗损失或其他设计，不能把本例三项说成所有VQ模型唯一训练目标。

## 7. 可运行量化与梯度算例

下面解码器设为恒等线性映射，只为了透明地验证梯度路径，不是假装已训练图像autoencoder。

```python
import torch
from torch import nn
from torch.nn import functional as F

z = torch.tensor([[0.8, 0.6]], requires_grad=True)
codebook = nn.Parameter(torch.tensor([[1., 0.], [0., 1.]]))
dist = (z[:, None, :] - codebook[None, :, :]).square().sum(-1)
ids = dist.argmin(-1)
e = codebook[ids]
z_st = z + (e - z).detach()
decoder = nn.Linear(2, 2, bias=False)
with torch.no_grad():
    decoder.weight.copy_(torch.eye(2))
recon = F.mse_loss(decoder(z_st), z.detach())
code_loss = F.mse_loss(e, z.detach())
commit_loss = 0.25 * F.mse_loss(z, e.detach())
loss = recon + code_loss + commit_loss
loss.backward()
print(ids.tolist(), e.detach().tolist())  # [0]、[[1.,0.]]
print(round(loss.item(), 4))              # 0.45，采用每维平均的MSE
print(z.grad, codebook.grad)             # 编码器与所选码本都有梯度
```

平方距离求和为0.4，代码里每维平均MSE为0.2，所以三个损失分别0.2、0.2、0.05，合计0.45。报告误差时必须写清“求和/平均、像素/潜空间、平方/绝对值”，否则数字不可比较。

## 8. 有了离散图像id，怎么让模型生成图像

先训练或获得视觉tokenizer，把训练图像编码成id序列。再训练一个自回归模型，在文字条件下预测这些视觉id。例如给“画一只红色小船”，序列可能是文本token、图像开始标记、256个视觉id、图像结束标记。

生成时模型逐个预测视觉id，再将id查码本并送入图像解码器，得到最终像素。于是“统一预测符号序列”成为理解与生成共享框架的一个选择，Chameleon、Emu3等是代表路线。

困难包括：图像序列可很长，逐token生成慢；局部id预测要形成全局一致对象；tokenizer重建上限限制最终图像质量；同一表示同时适合精细理解与生成不一定容易。这些问题涉及数据、模型和训练，不能用“量化损失”解释全部效果差异。

## 9. 混合路线如何打破二选一

理解任务希望保留语义、文字和关系；生成任务还要还原纹理、颜色和像素结构，两者对视觉表示的要求可以冲突。Janus的思路是分离理解与生成视觉编码路径，但共享统一的Transformer处理框架。其他路线让连续特征或语言hidden state去条件化扩散/flow生成器。

扩散/flow通常从噪声开始，通过多次预测或迭代恢复连续图像潜表示，再解码成像素；这与逐个生成离散码本id是不同生成机制。因而比较模型时应分别回答：输入图像表示是什么、生成目标是什么、输出通过哪个解码器变成图片。单看“连续/离散输入”不能决定全部能力。

## 10. 互动能说明什么，不能说明什么

[[widget:vq]]

本互动在RGB颜色空间找最近调色板颜色，让“有限原型会产生色带”肉眼可见。真实视觉VQ通常在学习到的潜空间量化，解码器能用上下文生成像素，因此不能拿右侧色带直接当作某真实模型重建，更不能把显示的RGB平均绝对误差当理解benchmark或commitment loss。

课堂操作：先固定网格，增大码本看误差；再解释如果改空间网格会发生什么。区分“每个位置能选多少符号”与“总共有多少位置”，比只拖一个滑块更重要。

## 练习

1. z=(0.2,0.9)，沿用两条码本，应选哪条？——答：到(1,0)平方距离1.45，到(0,1)为0.05，选id1。
2. K从1024改8192，16×16网格有多少token？——答：仍256；理想每id容量10bit变13bit。
3. 原图32×32的潜网格变64×64，自回归视觉步数怎样变？——答：1024变4096，4倍。
4. 为什么VQ需要straight-through或其他训练设计？——答：离散最近邻选择不能直接提供通常所需的连续梯度。
5. 连续理解编码器能与图像生成共存吗？——答：能，生成结构可以另行使用离散路径或连续扩散/flow路径。

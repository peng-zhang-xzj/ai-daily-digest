# L8 训练与对齐：答案损失怎样训练视觉接口，偏好优化怎样改变回答

建议时长50–60分钟。前置：L4的视觉前缀和逐词预测；本讲解释监督标签、梯度、冻结、LoRA与DPO。学完应能标出一个对话序列的loss位置，说明梯度流向，区分LLaVA教学配方与Qwen2.5-VL真实阶段，并提出可验证的幻觉治理实验。

## 1. 先问“优化什么”，再问“用几张卡”

模型结构规定信息怎么进入和传播；训练目标规定什么行为获得奖励。相同结构可以因数据、loss、冻结策略和解码方法不同而输出不同答案。

理解型VLM的一种核心任务是：给定图像I和提示x，让助手回答y获得高概率。对回答token的条件概率链求负对数：

`L = −Σₜ log Pθ(yₜ | I, x, y₁…yₜ₋₁)`。

θ表示要学习的参数；负对数让正确token概率低时损失大；对每个回答位置求和或平均，具体归一化策略应说明。这个目标不是直接比较“整句听起来好不好”，而是把回答拆成逐token监督。

## 2. teacher forcing与causal mask各解决一个问题

训练时，我们有标准回答“一只狗”，可以在预测“狗”时喂标准前文“一只”，这叫teacher forcing。推理时没有标准答案，前文来自模型自己生成，因此早期错误会改变后面的条件。

因果掩码causal mask让位置t不能读取未来位置。虽然训练batch里包含完整答案，但预测“狗”的位置只允许读图像、问题和答案前文，不能直接读到“狗”之后的目标。teacher forcing不是偷看目标，正确移位和掩码是关键。

常见实现的logits在位置t预测位置t+1的token，所以计算loss时做shift：`logits[:-1]`与`labels[1:]`对齐。漏了移位，模型可能被训练成“读到当前词再复述当前词”；模板错位则可能让提示标记也被当成回答训练。

## 3. 监督mask具体怎么标

[[figure:l8-label-shift]]

考虑一个简化序列：

| 位置 | 输入内容 | 是否作为目标label |
|---|---|---|
| 0–1 | 两个视觉输入位置 | 否 |
| 2 | USER角色标记 | 否 |
| 3 | 问题文本 | 否 |
| 4 | ASSISTANT角色前缀 | 否 |
| 5 | 回答第一个token“狗” | 是 |
| 6 | 回答第二token“坐着” | 是 |
| 7 | 回答结束符EOS | 通常是，按模板配置 |

许多训练代码用`-100`作为忽略label，这只是框架约定，不是词表中的特殊文字。“视觉位置不作为label”表示我们不要求在该位置预测视觉id，**不表示视觉输入没有参与答案计算或没有梯度**。

预测位置5的“狗”通常使用位置4的logits。只要模型注意力读取了前面的视觉信息，答案loss就能反向影响视觉输入路径。未冻结的连接器、视觉编码器仍可获得梯度。冻结是参数更新设置，label mask是监督位置设置，两者不能混为一谈。

多轮对话一般可对各轮助手回答提供监督，同时屏蔽用户段；system模板、角色边界和图像标记也需与checkpoint一致。不要只用字符串“找到最后一个ASSISTANT”来处理所有多轮数据，容易漏掉或误标监督。

## 4. 一段CPU代码，验证“图像没有label，但仍能收到梯度”

本例用两个占位向量模拟视觉输入，使用随机小Transformer，仅检查梯度与shift，不演示已训练的问答能力。

```python
import torch
from torch import nn
from torch.nn import functional as F

torch.manual_seed(11)
ids = torch.tensor([[1, 2, 3, 4, 8, 5, 6, 7]])
labels = torch.tensor([[-100, -100, -100, -100, -100, 5, 6, 7]])
embedding = nn.Embedding(20, 16)
layer = nn.TransformerEncoderLayer(16, 2, 32, dropout=0., batch_first=True)
readout = nn.Linear(16, 20)
inputs = embedding(ids)
inputs.retain_grad()
mask = torch.triu(torch.ones(8, 8, dtype=torch.bool), diagonal=1)
logits = readout(layer(inputs, src_mask=mask))
loss = F.cross_entropy(logits[:, :-1].reshape(-1, 20),
                       labels[:, 1:].reshape(-1), ignore_index=-100)
loss.backward()
print(int((labels[:, 1:] != -100).sum()))  # 3个有效回答目标
print(inputs.grad[0, :2].norm().item())  # 非零：前两视觉占位输入有梯度
```

真实视觉输入来自编码器与连接器，不是本例embedding表。若把视觉前向包在`no_grad`里，或错误地detach了连接器输出，梯度路径可能被截断；因此仅看参数`requires_grad`还不够，也需检查是否真的处于计算图中。

## 5. 冻结、全量更新与LoRA，分别改哪些参数

冻结视觉编码器：它仍把图像变成特征，但权重保持不变。若其输入是普通像素且无需输入梯度，可以省下该模块的一部分反向激活；若需要梯度通过冻结模块传回更早的可训练输入，不能无条件用no_grad。

冻结LLM、只训连接器：连接器较小、较稳，但仍需要LLM对输入的梯度来训练它。全量更新LLM提供更多适应自由度，也增加训练显存，并可能改变原有纯文本能力。解冻视觉编码器能适应新视觉任务，但低质小数据会带来漂移，因此常配更小学习率和任务验证。

LoRA把某些权重更新写成低秩形式：`W' = W + scale×BA`。若原权重为d_out×d_in，A为r×d_in，B为d_out×r，更新参数约为`r(d_in+d_out)`，r远小于两端维度。例如4096×4096矩阵全量更新约1678万参数，r=8的LoRA约65536参数，不计额外bias。

它减少的是可训练参数和相关优化器状态，不等于无需加载或运行底座，也不保证所有训练激活显存一起按同比例减少。选择哪些层、rank、缩放与数据任务都会影响结果。

## 7. 数据配比、packing与有效batch为什么会影响结果

如果多模态训练全是短caption，模型可能缺文档推理；全是长详细回答，模型可能倾向冗长描述；缺少纯文本任务，语言能力可能回退。数据混合既改变任务覆盖，也改变每个任务在总训练token中的权重，因此“占多少样本”与“占多少监督token”是不同口径。

packing把多个较短样本放进较长训练序列，减少padding浪费。若允许不相关样本彼此读取，它们会形成额外上下文，改变训练目标；隔离策略、位置重置和attention mask必须设计清楚，不可只把字符串拼接就称成正确packing。

梯度累积把多个小batch的梯度合在一起再更新。例如每卡2个样本、4卡、累积8步，有效样本batch为64；若样本长度和有效回答token差异大，loss归一化又会改变每个样本的实际权重。不要仅凭相同“有效batch”认为训练条件完全一致。

训练日志应同时记录总loss、任务分组验证、监督token量、梯度/参数状态及纯文本保持情况。loss下降可以来自容易的模板或数据重复，不必然带来未见任务能力。

## 8. DPO：用好/坏回答对优化相对偏好

SFT只告诉模型某个答案应出现；偏好对提供同一图像与问题下的好答案y⁺和较差答案y⁻。例如图里只有狗，y⁺是“图中有一只狗”，y⁻是“图中有一只狗和一只猫”。偏好标注要有视觉证据，不能仅因答案更长或语气更坚定就称为好答案。

DPO使用当前策略πθ和固定参考策略πref，计算：

```text
margin = [log πθ(y⁺|x) − log πref(y⁺|x)]
       − [log πθ(y⁻|x) − log πref(y⁻|x)]
L_DPO = −log sigmoid(β × margin)
```

x包含图像与提示。对整段答案的log概率通常由回答token的log概率求和得到，需处理模板与mask；不同长度、数据格式和偏好构造会影响结果。参考策略提供相对基准，β控制优化尺度，公式不等于一个直接的“事实真假”检测器。

若当前相对参考对好答案提高了0.4的log概率，对坏答案降低了0.2，则margin=0.6。取β=1，偏好概率sigmoid(0.6)约0.6457，损失约0.4375。若两者改善相同，margin=0，损失为log2≈0.6931；模型要拉开相对差异。

DPO可以减少某些幻觉或改善风格，但效果依赖偏好数据。若“好答案”同样包含错误视觉细节，优化会奖励错误；过度偏好保守回答还可能把可回答问题也变成拒答。

## 9. 幻觉治理要拆层，而不是一句“再对齐”

幻觉包括不存在对象、错误属性、数量/位置错误、OCR数字错误或视频事件时间错误，不只“编出一只猫”。语言先验强、视觉证据丢失、训练标签不忠实、解码随机性与提示歧义都可能贡献。

先按错误定位做对照：固定模型与prompt，只提高分辨率，若小字错误明显减少，视觉信息瓶颈值得优先处理；替换或遮挡图像而答案基本不变，可能是语言先验/任务捷径；纠正caption后重新训练小实验，可以检查数据忠实性；比较greedy与采样，可以区分部分解码影响。

拒答不是可靠性的唯一指标。一个模型对所有图都说“无法判断”，对象幻觉可能少，却失去有用召回；一个模型总回答“有”，可能召回高却假阳性很多。L9用混淆矩阵和任务分组评测继续量化这些权衡。

## 10. 训练前后的可检查清单

训练前抽查真实tokenized序列：图像占位展开正确吗，模板与角色对吗，answer labels移位对吗，未来位置被遮住吗，有效监督token为零的样本被处理了吗？冻结/LoRA模块与学习率符合阶段吗？

训练后不仅看平均loss：固定一组有证据的图像问题，按OCR、关系、数量、幻觉和格式分别比较；留出与训练不重合的数据；保留checkpoint、数据版本、prompt和解码参数。小数据跑通只证明接口可工作，不等于已完成能力与安全验证。

## 练习

1. 图像label为−100，能否因此断言连接器没有梯度？——答：不能，答案loss可通过注意力路径回传；取决于冻结与计算图。
2. 为什么logits与labels通常要移位？——答：位置t的输出预测下一位置token，而不是复述当前输入。
3. 4096矩阵r=8的LoRA更新多少参数？——答：8×(4096+4096)=65536，未计额外参数；底座仍需运行。
4. margin=0时DPO损失是多少？——答：−log0.5≈0.6931，与β无关。
5. Qwen2.5-VL的SFT是否等于LLaVA阶段一“只训投影”？——答：不是，具体阶段与可训练模块需按对应报告配置。
6. 总拒答能证明安全任务可靠吗？——答：不能，必须同时评价正确回答、漏判、误判、拒答和业务成本。

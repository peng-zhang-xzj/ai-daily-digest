# L1 从看图说话到视觉注意力：模型生成一个词时，到底在看什么

建议授课45–55分钟。前置知识只有“图片可以写成数字、向量是一组数字”。本讲会定义所有必要符号，不要求先懂LSTM或Transformer。

学完应能：画出图像到句子的完整路径；手算注意力权重与上下文；说明注意力如何参与训练；区别早期视觉注意力、Transformer交叉注意力与自注意力。

## 1. 先明确任务，而不是先背模型名

输入是一张图，输出是一句话，例如“一只狗坐在草地上”。机器并不是先得到这句话再翻译：它要连续做多次决策，先预测“一”，再预测“只”，再预测“狗”，直到结束符。若词表大小为V，每步输出V个候选词的概率。

写成概率链是：

`P(整句 | 图像) = ∏ₜ P(第t个词 | 图像, 前面已经出现的词)`。

竖线表示“在这些条件已知的情况下”；乘积表示每一步的条件概率连起来。这里的词只是教学单位，实际实现可能用词、子词或字符。训练时，我们用图像及人工描述告诉模型哪些词应当获得高概率；推理时，没有标准答案，模型要把自己生成的词继续喂回去。

## 2. 2015年前后的起点：CNN看图，LSTM组织句子

CNN即卷积神经网络。它用许多可学习的小滤波器扫过图片：浅层常响应边缘和纹理，深层把局部响应组合成更复杂的视觉特征。一个数字响应不是一个人工定义的“狗”标签；它是模型在训练中学出的表示。

最简的看图说话方案把CNN最终特征压成一个向量v，交给语言解码器。Show and Tell的具体做法是把图像嵌入作为LSTM初始时间步的输入，然后依次输入词的嵌入。其他编码器—解码器也可以用v初始化隐藏状态，不能把这些实现细节混为一谈。

LSTM是带记忆的循环神经网络。每步读取上一词的向量xₜ，结合上一状态，得到新状态，再预测下一词。它维护两份量：隐藏状态hₜ，供当前预测使用；记忆状态mₜ，帮助信息跨很多步保留。

可把一轮更新写成：

```text
i = sigmoid(Wi[xₜ,hₜ₋₁] + bi)    输入门：写入多少新信息
f = sigmoid(Wf[xₜ,hₜ₋₁] + bf)    遗忘门：保留多少旧记忆
o = sigmoid(Wo[xₜ,hₜ₋₁] + bo)    输出门：暴露多少记忆
g = tanh(Wg[xₜ,hₜ₋₁] + bg)       候选新信息
mₜ = f ⊙ mₜ₋₁ + i ⊙ g
hₜ = o ⊙ tanh(mₜ)
```

`[x,h]`表示拼接；`⊙`表示对应位置相乘；W和b都是训练出的参数。sigmoid把数压到0–1，像连续开关；tanh把数压到−1–1。无需背这些门的名字：关键是hₜ含有“前面已经说了什么”的信息，却不天然知道下一词应该访问图片的哪个区域。

## 3. 注意力为什么会登场：不是所有输出词都需要同一份图像信息

[[figure:l1-attention-story]]

单向量v必须同时保留狗、草地、红球、相互位置和背景；但生成“狗”与生成“红色”所需证据不同。长句还要依赖很早输入的图像信息，固定瓶颈可能让小物体和局部属性被淹没。

Show, Attend and Tell（2015）的变化不是凭空增加一个神秘“注意力模块”，而是两个具体设计：第一，不把整图立即压成一个向量，保留CNN的空间特征网格；第二，让语言解码器在每个输出步骤，根据已有状态对这些区域重新分配权重。

假设CNN输出14×14×512。前两维表示196个空间位置，最后一维是每个位置的512维特征。把它重排成矩阵A，形状为`[196,512]`；第i行aᵢ对应图片某个位置的特征。因卷积感受野可能覆盖较大区域，它不是精确的像素框，也不保证一行刚好对应一个物体。

于是模型不必每次“重新看CNN”：CNN可先计算一次A；生成每个词时，对同一份A做不同读取。这就是注意力解决的接口问题——**按当前语言需要，从保留的视觉位置中读取信息**。

## 4. 一步视觉注意力，严格拆成四个运算

步骤一，用解码器上一步的hₜ₋₁表达当前需求。例如已经说“一只”，状态可能倾向寻找可接上的动物名；这是训练学出的趋势，不是手写语法规则。

步骤二，对每个视觉位置打分。经典加性注意力的一种写法是：

`eₜᵢ = uᵀ tanh(Wa aᵢ + Wh hₜ₋₁ + b)`。

Wa把视觉特征映到共同的中间维度，Wh把语言状态映到同一维度；两者相加后过tanh，再由向量u读成一个数eₜᵢ。上标T表示转置，向量的点积把一组数合成一个标量。e不是概率，可以为负，也不要求总和为1。

步骤三，把分数归一化：

`αₜᵢ = exp(eₜᵢ) / Σⱼ exp(eₜⱼ)`。

这叫softmax。每个α非负，所有区域的α加起来为1，因此可理解成这一步读取各区域的比例。实际实现常先减去分数最大值再取指数，概率不变，但能避免大数溢出。

步骤四，得到上下文向量：

`zₜ = Σᵢ αₜᵢ aᵢ`。

zₜ仍是512维，不是196维；196个权重把196个512维向量加权合成一个512维向量。然后把`[上一词嵌入, zₜ]`交给LSTM更新hₜ，再通过线性层和softmax得到下一词概率。也可以在输出层再次使用zₜ；不同模型的连接方式会不同。

```text
图像 → CNN → A=[所有位置的视觉特征] ───────────────┐
                                                  │
上一状态h + A → 区域打分e → softmax权重α → 加权读取z│
                                                  ▼
上一词嵌入x + z → LSTM → 当前状态h → 词表概率 → 下一词
                             │                    │
                             └─────下一步─────────┘
```

## 5. 完整手算：注意力不是一句“看向狗”就解释完了

[[figure:l1-attention-math]]

用3个位置、每处2维特征代替196×512，方便手算。设：

| 位置 | 特征向量 | 仅用于理解的区域备注 |
|---|---|---|
| 1 | a₁=(1,0) | 一个区域 |
| 2 | a₂=(0,1) | 另一个区域 |
| 3 | a₃=(1,1) | 第三个区域 |

这些数字是教学构造，不是真实CNN输出。假设经过打分网络得到`e=(ln4, ln1, ln5)`。取指数得(4,1,5)，和是10，因此`α=(0.4,0.1,0.5)`。

上下文是：

`z = 0.4(1,0) + 0.1(0,1) + 0.5(1,1) = (0.9,0.6)`。

下一步语言状态变了，分数可能变成`(ln1,ln8,ln1)`，权重变成(0.1,0.8,0.1)，上下文变成(0.2,0.9)。同一张图提供了两种不同的读取结果，这才是“生成不同词时看不同区域”的数值含义。

若某个极简输出层给“狗/球/草地”的分数分别为`2z₁、2z₂、z₁+z₂`，第一步得(1.8,1.2,1.5)，softmax约为(0.437,0.240,0.324)。这只是人为构造的示范，不表明特征第一维天然代表狗；真实模型必须从大量图像—句子对学出这样的读出关系。

## 6. 训练时怎么知道“该看哪里”？大多没有逐词框标注

通常训练集给整张图和整句话，并没有“狗”这个词对应哪个位置的监督。模型先按当前参数算出α、z及词表概率；若正确词是“狗”，损失是`−log P(狗)`。概率越低，损失越大。

softmax、加权和、LSTM和词表输出都是可微运算。反向传播把“正确词概率不够高”的信号传到打分网络，从而调整Wa、Wh、u，必要时也调整CNN。**注意力权重是为了更好预测训练词而学出来的，不是额外的人眼标注自动落入模型。**

训练通常使用teacher forcing：第t步喂标准答案的上一词，便于对训练样本做批处理并稳定学习，但LSTM各时间步仍依次更新；推理只能喂模型自己刚生成的词。前面猜错可能影响后面，这种训练—推理条件差异是误差累积的重要来源。

soft attention使用所有位置的加权和，容易直接求梯度。原论文还讨论hard attention：采样某个位置再读取，采样选择不可直接按普通方式求导，需要其他梯度估计方法。两者不要仅凭“权重很尖”来区分：soft权重接近one-hot仍然是soft attention。

## 7. 可运行的最小实现：接口与梯度，而不是假装训练完一个模型

下面CPU代码只演示一个生成步骤。随机特征代替CNN输出；随机初始化的模型没有看图说话能力。

```python
import torch
from torch import nn

torch.manual_seed(7)
B, L, D, H, E, V = 2, 3, 4, 5, 3, 6
A = torch.randn(B, L, D)          # 两张图，各3个区域，各4维
h = torch.zeros(B, H)            # 上一步语言隐藏状态
memory = torch.zeros(B, H)
x = torch.randn(B, E)            # 上一词嵌入
visual_proj = nn.Linear(D, H)
state_proj = nn.Linear(H, H, bias=False)
score = nn.Linear(H, 1, bias=False)
cell = nn.LSTMCell(E + D, H)
readout = nn.Linear(H, V)

e = score(torch.tanh(visual_proj(A) + state_proj(h)[:, None, :]))
e = e.squeeze(-1)                # [B,L]，每处一个分数
alpha = e.softmax(dim=-1)        # 对“区域维”归一化
z = torch.bmm(alpha[:, None, :], A).squeeze(1)  # [B,D]
h_new, memory_new = cell(torch.cat([x, z], dim=-1), (h, memory))
logits = readout(h_new)           # [B,V]
loss = nn.functional.cross_entropy(logits, torch.tensor([1, 2]))
loss.backward()
print(alpha.sum(-1))             # 两个值均约为1
print(z.shape, logits.shape)     # [2,4]、[2,6]
print(score.weight.grad.norm())  # 非零：词损失可以训练注意力
```

最常见的实现错误是沿特征维做softmax，得到“每个特征通道的权重”，却声称在选区域。第二个错误是把α与A相乘后忘了对区域求和，形状就不能正确进入LSTM。第三个是训练时把未来答案喂进当前需求状态，造成信息泄漏。

## 8. 如何理解注意力图，及其局限

把α的196个值重新排成14×14，插值到图片大小，就能画热图。它告诉你这一层在这一时刻如何分配读取权重，却不能充分证明输出的原因：特征可能已经包含邻域信息，不同权重组合可能得到近似上下文，语言先验也能主导答案。

例如图片里有狗和球，模型给狗区域高权重，却仍输出“猫”；这可能是视觉特征分类错了，也可能是词表读出错了。反过来，权重较分散也不一定失败。因此应同时检查输出、注意力、遮挡或替换区域后的变化，避免只凭热图解释可靠性。

## 9. 与Transformer是什么关系？思想相通，运算结构不同

早期这一步是交叉模态读取：语言状态提供“想找什么”，视觉位置提供“可读的信息”。后来的Transformer交叉注意力把需求映成Q（query）、视觉特征映成K（key）和V（value），用点积相似度生成权重：`softmax(QKᵀ/√d)V`。它通常有多头和多层，但本质仍然是按需求加权读取。

自注意力则让Q、K、V来自同一序列，例如一串文本词彼此读取，或视觉patch彼此读取。“自/交叉”描述信息来自哪里；“加性/点积”描述如何打分；“soft/hard”描述如何选择与求梯度，三个分类不能混在一起。

## 10. 从描述到VQA：把“用户想知道什么”也加入条件

image captioning只要求给图写一句描述；视觉问答VQA则给图像I与问题q，要求答案a。目标从`P(句子|I)`变成`P(a|I,q)`。问“球是什么颜色”和问“有几只狗”，同一图需要读取不同证据，不能每次都只生成默认caption。

早期实现可以先用一个文本编码器把问题变成向量，再与图像特征结合，或让问题状态直接参与视觉注意力打分。输出既可以是一个固定答案类别的分类头，例如颜色/数字候选；也可以是逐词生成器。分类方法容易判分但词表有限，生成方法更灵活却需要处理同义表达与答案格式。

举例：图片上有两只狗和一个红球。问题“球是什么颜色？”需要定位球区域并读取颜色；“有几只狗？”需要覆盖多个狗区域并区分不同实例。只把注意力集中到一只狗，不足以保证正确计数，因为注意力是加权信息读取，不是显式对象计数器。

还要防语言捷径：若训练集里“香蕉是什么颜色”多数答案都是黄色，模型可能不看图也答对。验证视觉依赖时，可对照不同颜色的香蕉图、遮挡图像、固定问题换图，看答案是否随证据变化。原始VQA数据集在2015年推动了这类任务，但VQA这个名字本身不保证模型在做可靠推理。

## 练习

1. α=(0.2,0.3,0.5)，沿用上表A，z是多少？答案：(0.7,0.8)。
2. 所有分数都加100，权重会变吗？答案：数学上不变，分子分母有共同倍数；实现应减max避免溢出。
3. 为什么只有一张图，也要每个词重新算α？答案：图像没变，但语言状态和当前读取需求变了。
4. 把L由196改为784，z的维度会变吗？答案：D固定时仍为D；权重长度与计算量会变。
5. 注意力热图落在狗身上，能证明模型真的理解狗吗？答案：不能，需要输出和干预等额外证据。
